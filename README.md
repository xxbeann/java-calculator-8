# java-calculator-precourse

### 요구분석

1. 양수는 0보다 큰 정수만 허용하고 실수(유리수)는 허용하지 않는다.
2. `“,”`, `“:”` 를 기본 구분자로 갖는다.
3. 구분자를 기준으로 문자열에서 숫자를 추출하여 숫자의 합을 반환한다.
4. 사용자는 커스텀 구분자를 지정할 수 있다.
5. 커스텀 구분자는 `“//;\n”` 형식으로 지정한다.
6. 커스텀 구분자를 지정할 경우 기본 구분자는 사용되지 않는다.
7. 커스텀 구분자를 지정했을 때, 기본 구분자를 사용하면 예외를 발생시킨 후 애플리케이션을 종료시킨다.
8. 커스텀 구분자를 지정했을경우, 문자열에서 숫자를 추출하여 숫자의 합을 반환한다.
9. 사용자가 위에서 지정된 이외의 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료한다.

### 기능구현

1. 사용자 입력 기능
2. 사용자 입력 예외처리
3. 덧셈 기능
